是公还是母这类二选一，固定句式只说记得这个人、没记下这个属性，不会把其中一边说成已经记住的事实。

问句不会再被存成事实。回答时也不引用问句形状的记录，更不会把「啥名」当成名字。瑞典工匠叫啥名仍然答出工匠本人。

谁磨的要答到打磨的那个人。父亲只是中间一跳，走不到工匠就弃权，不把父亲当成答案。那口子、媳妇、夫人、老伴这类没教过的配偶，和妻子一样用固定句式，不引用同一句里的塔。

守护人、看守人、守塔人叫什么，答的是守护的那个人，不是名叫的塔。四十二米的塔是谁守的、霜降的盐叫什么、盐的那个镇的第一座灯塔，只要取值种类对得上就答出来。
