# desktop-v0.2.32

0.2.30 和 0.2.31 都还没有通过独立验收。这一版只修已经能在回答路径上复现的几类错，不把 0.2.31 的 20/20 小集当成通过。

同一句里的国家不能拿去回答这座建筑是哪国，国家也不能被答成哪座塔。问谁建造、谁设计，不能把守护的人或磨透镜的人说成那个角色。没写过的兄弟姐妹、叔叔、爷爷，不能用宠物的名字来答。

「你知道吗」前面的狗、技能、兄弟姐妹和猫会进待巩固。没有句号的「有多高」、写留言、以及「告诉我谁」不再当成事实留下。以前那几条正当陈述还在。空记忆里，前半句点了名字、后半句再问另一个角色，不再交给基座编出人名。

新的整本训练和中断后续测还没完成，这里不报那两项的结果。

后端和训练进程认 OMP、MKL、OpenBLAS 传入的线程数。没传时每个进程用 2 条，不再按全部核心开线程。导入 PDF 摘重点时会按段报告进度，单次生成最多 20 秒，整段摘录默认 180 秒。超时或取消会留下已经抽出的句子，再导入可以接着做，不再停在 85% 不响。
