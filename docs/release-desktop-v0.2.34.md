# desktop-v0.2.34

0.2.33 的安装包和出处核对是过的，独立对话验收没有过。这一版不把 0.2.33 当成已经验过。

多跳问题改成沿已存事实的边走。每一跳都要有一条事实，正好连着这两个人或事物，关系也要一致。没有这条边就弃权，不用链上另一个人的宠物、年份、工作地点或建筑来回答。颜色和牌子也分开。

已经记下的取值，用「是 A 还是 B」来问时会回答那个取值，但这句话不会再被当成事实存进待巩固。「跟你说」「告诉你」后面的事实还会留下。「你知道吗」不会被当成要改记忆。认不出实体和属性时，弃权用固定的一句话，不再把问句碎片拼进回答。

记忆里没有这个人或事物时，不再把属性题交给基座编一个现实答案。0.2.32 已经跑过清理的家里，分类器更新后会再清一遍没有问号的客气要求和选择问句。
