「我是翻译，还是作家」是陈述，不是二选一的问句。书名《十万个为什么》里的「为什么」也不是在提问。清理不再因为这些字就隔离陈述句。带问号或「吗」的「是A还是B」，以及没有逗号的「是男的还是女的」，仍然隔离。

问猫的名字不会拿学校的名字来答。问学校也不会拿猫的名字来答：学校没记过就弃权，不会把云朵说成学校。别人的学校也不会拿沈星河的猫或沈星河的学校来答。弃权说完整的属性，例如「我没记过沈星河的学校。」「我没记过沈星河在哪所学校上学。」不会把问句截成「学校叫」。验收里只要出现这种答错的取值，或者弃权句停在叫、是、的、于，任务直接失败，不再用九成弃权率把这一条放过。

0.2.15 当时按「翻译」「推荐」这些字直接删事实，没有留下备份，也没有隔离文件，那些句子无法自动找回来。后来的清理如果把陈述句放进了隔离区或 memory.bak，这次启动会把不再算作垃圾的句子放回去，备份文件本身不动。
