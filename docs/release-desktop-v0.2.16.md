年份、年限、人数必须对上问句要的种类。对不上就弃权，不引用另一句里的塔名或「十六面」。一跳而且原文里写了这个属性时，仍直接回答。

从 0.2.7 升级后的同一次启动里，基座权重会先落到 cpu，再回答。不会停在 meta 设备上。

## 0.2.14 误存事实的清理

只处理 0.2.14 写下的条目：事实自己带 `app_version: 0.2.14`，或者完全没有版本戳、并且写在 2026-11-05 04:53 UTC 到 08:59 UTC 之间。0.2.7 以及其他版本的记忆不会被改。

整句必须是要求或问句才移走：句首是「请 / 帮我 / 给我 / 写一」，或者以问号、吗、呢结尾。句子中间出现「翻译」「推荐」不算。下面这些会原样留下：

- 我的职业是翻译
- 我是一名翻译
- 她喜欢别人推荐的书
- 我做产品推荐工作
- 我喜欢写诗

清理只跑一次，记在 `migrations/cleanup-0214.json`。动文件之前会把原件复制到旁边的 `memory.bak-<时间>`，这份备份不会自动删。移走的条目放在 `cleaned/0214-junk.json`，可以恢复。
