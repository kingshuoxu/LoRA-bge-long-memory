# desktop-v0.2.31

0.2.30 的安装包校验是齐的，功能验收没有过。这一版不把 0.2.30 当成已经验过。

学校记过以后，「是在哪个学校读书的」「现在在哪儿念书」「是哪个学校毕业的」「是哪个学校的学生」都回答校名，不再说没记过，也不再把问句收成「是的学校」。没教过的学校仍然弃权，也不会拿猫的名字来答。

训练进程已经不在时，重新打开会把任务标成中断或已停止。取消和继续不再被「已有训练在进行」挡住，已经记下的事实不动。

0.2.29 写过的恢复标记不会挡住后来才认出的陈述。隔离区和待巩固里被误清的句子还会放回去一次，已经在的不复制。没有备份的 0.2.15 删除仍然找不回来。

转述里的「为什么」留下。没有问号的「住在哪里」「推荐几本」仍是问句或要求。问句里的「哪里」不能当成住址。前面的事实加上「你知道吗」会记住事实，不会记住问句的前提。弃权不再停在「你知道」。

发布说明里会带上这次 Actions 运行号和提交。0.2.30 那次打包四个系统都成功，但上传任务没有被创建，工作流结论是失败，安装包是事后从产物补传到发布页的。
