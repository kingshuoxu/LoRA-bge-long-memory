# desktop-v0.2.36

0.2.35 的安装包和出处核对是过的，独立对话验收没有过。这一版不把 0.2.34 或 0.2.35 当成已经验过。

问一个人或一件事时，只沿着已经记下的关系走。某一跳没有正好那条边、名字差一个字、或者问的属性和句子里的另一种年份对不上，就回答「这件事不在记忆里。」，不再拿另一条已存取值来填。

同一句话里先说事实再提问，逗号或句号隔开都会留下事实，并且这一句回复就用刚记下的事实来回答。职业、老家、养的狗、偏爱的花，以及工坊的创立年份、总部、创始人、产品和员工人数，都从记下的那一句来答。记忆里有的「是 A 还是 B」回答记下的那一边；问句没有点到已存的人或取值时，不把常识选择题收成弃权。法国、中国这类首都按核对过的答案说；没见过的专名说「我不知道」，不交给基座编。上一轮用恢复功能放回去的问句，下次启动会再清掉。
