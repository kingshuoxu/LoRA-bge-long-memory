# desktop-v0.2.33

0.2.32 的安装包和线程、PDF 时限检查是过的，独立对话验收没有过。这一版不把 0.2.32 当成已经验过。

问句要的关系和种类都得落在同一句上，否则弃权：亲属不是宠物，国籍不是建筑，设计不是值守，去世的年份也不是旁边另一件事的年份。句子前半截点到的人，不会被当成后半句的答案。

「你知道吗」放在事实前面或后面，事实仍会留下，也不会被当成要改记忆。是 A 还是 B、带问号的句子、能不能帮我写、以及「有多高，建了多久」这种没写问号的问句，不会进待巩固。上一轮误放回去的问句和要求会按隔离区原文拿掉，正当的转述还留着。
